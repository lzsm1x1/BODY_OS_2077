# 义体维护终端 v0.0.10 说明文档

> 赛博朋克 2077 义体改造界面风格的身体部位健康记录网页
> 版本：v0.0.10 · 更新日期：2026-11-11 · 身份：yxz

## 一、项目简介

一个仿照《赛博朋克 2077》义体装备界面的本地健康记录工具。中央为可交互的人体全息图（正面/背面，关节贴图在四肢躯干的上层），鼠标悬停部位高亮并**按状态显示对应颜色**，点击部位即可记录该部位的健康状态（需治疗 / 不适 / 需锻炼 / 正常，单选）和备注，**选择状态或修改备注后立即自动保存到页面**。**所有部位默认状态为「正常」**。左侧部位列表按区域分组框展示。界面有一条持续扫描的青色横线，扫过异常部位时该部位按状态**快速渐亮再渐灭**（不适=黄光、需治疗=红光、需锻炼=绿光）。**点底栏「保存到文件」直接把完整数据写入你绑定的数据文件夹**（在「高级设置 → 保存路径」配置一次，之后静默覆盖写 `body_records.json`），不再只依赖浏览器缓存。所有数据本地处理，不上传、不联网，并带身份核对（本机身份为 **yxz**）。

## 三、快速开始

直接双击 `义体维护终端.html` 用浏览器（推荐 Chrome / Edge）打开即可。无需安装任何东西、无需联网。

**数据怎么存（重要）**：
- **页面内自动保存**：选择状态/改备注后立即写入浏览器存储（localStorage），关闭页面再打开，数据还在。
- **保存到文件**：点底栏「保存到文件」，会**直接写入你指定的数据文件夹**（默认建议指到 `F:\AIproject\义体记录\数据备份\`），文件名固定为 `body_records.json`，每次覆盖为最新全量数据，同时生成一条全身快照存档。**文件夹只需在「高级设置 → 保存路径 → 选择 / 更换数据文件夹」里配置一次**，之后保存直接静默写入（仅在 Chrome / Edge 支持）。
- 底栏出现「● 未存盘」= 有改动还没写成文件，建议点一下「保存到文件」。
- **再次打开页面时**：浏览器安全限制不允许网页自动读取硬盘文件，所以页面先加载上次的页面内缓存；要读最新文件，点「高级设置 → 载入数据文件」，会列出数据文件夹里的 JSON 文件，点一下即可载入（顶部也会提示未存盘/缓存为空）。
- 缓存上限约 5 MB，正常使用（快照已自动裁剪，见第五节）不会撑满。

**中央人体图的渲染层次（v0.0.9 起）**——全部用 SVG + CSS 实现，没有任何图片素材：

| 层 | 作用 | 视觉表现 |
|---|---|---|
| 底座光雾 | 让人形「浮」在暗场里 | 人体背后一团极淡的青色径向光 |
| 全息轮廓层 | 光从身体内部透出来 | 同一份 50 个部位的图形复制一份做模糊，垫在实体下面，边缘自然发亮；状态色会一起透出来 |
| 内透光 | 投影的体积感 | 再叠一层轻微模糊的同一图形 |
| 扫描纹理 | 全息投影的横向纹路 | 4px 间距的细横线，**只出现在人体轮廓内部**（用人体轮廓做裁剪） |
| 色差错位 | 信号不稳的轻微偏色 | 轮廓复制两层、错开 1.4px，分别偏青和偏洋红 |
| 呼吸光 | 异常部位持续「活着」 | 需治疗/不适/需锻炼的部位以约 2.4 秒一个来回缓慢亮暗（v0.0.10 起，替代旧的「扫过才闪一下」） |
| 扫描带 | 机器在扫你 | 一条亮头在下的光带，5 秒一轮自上而下，尾部拖光；光带**压到哪个部位，哪个部位的描边与填充就柔和提亮**（0.5 秒缓动进出，无跳变） |
| HUD 装饰 | 界面感 | 琥珀金四角括号、两条点线椭圆环（缓慢流动）、左右两列刻度、左上「扫描中」、右上「身份 yxz」 |

配色分工：**机体=青色**（状态色覆盖），**HUD 装饰=琥珀金 `#ffb02e`**（刻意避开「不适」的黄 `#fcee0a`，不会混淆）。所有装饰层都设了 `pointer-events:none`，不影响点选部位。

## 五、使用方法

### 1. 记录身体状态

1. 鼠标悬停人体部位 → 部位霓虹高亮，提示框颜色跟随该部位状态（不适=黄、需治疗=红、需锻炼=绿、正常=青）；
2. 点击部位（人体图或左侧列表均可）→ 右侧「部位详情」面板打开；
3. **选择状态**（单选，顺序：需治疗 / 不适 / 需锻炼 / 正常，默认勾选「正常」）→ **点击即自动保存**；
4. 填写备注（症状、诱因、医生建议等）→ 停止输入 1 秒后自动保存。

**分状态天数（v0.0.10 起）**：不适、需治疗、需锻炼**各自独立计天数**，互不覆盖。部位名称右边显示**当前状态**的天数（例如「胸  需治疗 3 天」）；左侧部位列表同样显示（例如「胸 [需治疗] 需治疗 3 天」）。规则：

- 第一次标记某异常状态 → 该状态从**「X 0 天」**起算，次日为 1 天；
- 切换到另一异常状态（如 不适 → 需治疗）→ 需治疗从 0 天重新起算，**不适的天数保留**（再切回不适时接着原来的天数继续）；
- 切回「正常」→ **该部位所有状态的天数立即清零**；
- 文字颜色跟随当前状态色。

左侧「部位列表」按 头部 / 颈部 / 躯干 / 上肢 / 下肢 五组显示全部 50 个部位：**分组标题字体放大**，每组的子器官**用一个边框框起来**。点击列表项与点击人体部位效果完全相同（会自动切换正/背面视图）。灰色名字 = 尚无记录的部位（默认正常）。

**状态筛选（v0.0.10 起）**：列表顶部有四个小按钮 **全部 / 不适 / 需治疗 / 需锻炼**——点哪个就只显示该状态的部位，没有该状态的分组整体隐藏；**再点一次**（或点「全部」）恢复完整列表。筛选后没有匹配部位时会显示提示文案。筛选状态下点击列表项照常打开详情。

### 2. 状态说明与颜色

| 状态 | 颜色 | 用途 | 人体图 |
|---|---|---|---|
| 不适 | **黄色** | 该部位不舒服、疼痛 | 黄色高亮 |
| 需治疗 | **红色** | 需要就医/治疗 | 红色高亮 |
| 需锻炼 | 绿色 | 需要针对性锻炼/康复训练 | 绿色高亮 |
| 正常 | 青白色（人体图不着色） | 已检查确认无问题 | 保持默认青色 |

**单选规则**：一个部位同一时间只能有一种状态。未记录的部位默认视为「正常」。统计栏和角标只统计异常部位（不含正常）。

### 3. 正面 / 背面切换

中央顶部「正面 / 背面」按钮切换人体视图。**按钮上的红色角标数字 = 该视图下有异常记录（不含"正常"）的部位数量**，一眼看出正反面各有几处问题。

### 4. 扫描带与呼吸光

界面中央有一条青色光带持续从上往下扫描人体（约 5 秒一轮）。v0.0.10 起，异常部位的发光是**持续的呼吸光**而非一次性闪烁：

- **呼吸光**：被标记为 不适 / 需治疗 / 需锻炼 的部位**始终**以约 2.4 秒一个来回的速度缓慢亮暗（黄/红/绿），像监护仪上"还活着"的信号；外层光晕跟着一起呼吸；
- **扫描增强**：光带**压到哪个部位，哪个部位的描边与填充就柔和提亮、描边加粗**，光带走开后 0.5 秒缓动回落——全程没有突兀的跳变；
- 正常 / 无记录的部位只在被光带压到时轻微提亮一下，随即平复。

这是一种被动的全身巡检提示，无需任何操作即可快速定位有问题的部位。

### 5. 单部位历史快照：恢复与删除

每次自动保存都会为该部位生成一条带时间戳的历史快照（**1 分钟内同状态的连续保存会自动合并为一条**，例如连续修改备注不会刷屏），显示在右侧「历史快照（本部位）」列表中。

每条快照右上角有两个按钮：

- **恢复**：把当时的状态和备注载入面板并**立即自动保存生效**，适合记录反复出现的老毛病；
- **删除**：删除这一条快照（会二次确认，不可恢复）。支持**逐条挑着删**，例如 4 条记录里删掉中间 2 条、只留最早和最新。

### 6. 全身快照与保存到文件

- **自动快照**：每次自动保存任何部位时，系统会自动生成/更新一条全身快照（10 分钟内的多次保存合并为一条）。
- **保存到文件**：点底栏「**保存到文件**」会做两件事——生成一条独立的全身快照存档 + 把完整数据写入数据文件夹的 `body_records.json`。适合在体检后、治疗前后等关键节点存档。
  - 首次使用会弹出目录选择框：选到 `F:\AIproject\义体记录\数据备份\`（或你习惯的目录），浏览器会记住它；
  - 之后每次点「保存到文件」**直接静默覆盖写同一个文件**，不再弹窗；
  - 若浏览器不支持（Firefox / Safari）会自动降级为下载一个带时间戳的 JSON 文件；若是「写不进去」（权限被拒 / 目录不可写），会提示具体原因并询问是否下载一份临时备份。
- **回看快照**：点击底栏「回看快照」打开面板，左侧是快照时间列表，右侧显示该时刻全身所有部位的记录详情。
- 点击「在人体图上查看」进入**回看模式**：人体图、部位列表、角标、统计全部显示那个时刻的状态（只读，顶部有黄色横幅提示），可用来对比「上周 vs 现在」的恢复情况。
- 点击横幅上的「返回当前」（或按 Esc）退出回看模式。

**快照保留策略**（防止数据越积越大）：保留最近 **300 条**明细快照；更早的按**周**只留 1 条；超过 1 年的按**月**只留 1 条。所以数据文件长期稳定在 1 MB 上下。

### 7. 身份核对

本机身份固定为 **yxz**，数据文件中记录身份字段。载入 JSON 时如果数据属于其他人（身份字段不是 yxz），会提示「⚠ 信息错误」并拒绝载入，防止误载入他人健康数据。

### 8. 载入 / 清空数据文件

在「高级设置」弹窗中：

- **载入数据文件**：弹出文件列表，**优先列出数据文件夹里的所有 JSON**（按修改时间倒序），点一下即载入；也可以点「从其他位置选择文件…」手动挑选。载入会校验身份并二次确认。
- **清空数据**：删除全部记录和快照，需两次确认，不可恢复。

> v0.0.8 起移除了「下载数据文件」按钮：它和底栏「保存到文件」重复。真需要一份独立的时间点备份时，用「保存到文件」写入数据文件夹后，把 `body_records.json` 复制一份改名即可。

### 9. 高级设置

底栏「高级设置」弹窗分两块：

**① 保存路径**——列出各子文件夹的绝对路径作为参考（数据文件夹 / 数据文件 / 文档 / 资源），「项目根目录」可直接编辑（默认 `F:\AIproject\义体记录`）；下方显示**已绑定文件夹**与**读写权限状态**（读写已授权 / 需要重新授权 / 授权被拒绝 / 未绑定），可解除绑定；再下面一行是状态说明，选择失败时会变红并写出具体原因。选择 / 更换数据文件夹时会顺带做一次**写入自检**（建一个临时文件再删掉），提前发现「选得到却写不进去」的目录。

**② 数据文件**——载入 / 清空。高频的「保存到文件」「回看快照」仍直接放在底栏。

## 六、数据存储说明

页面内数据存在浏览器 localStorage（键名 `bodyOS_records_v1`），保存出的 JSON 文件结构：

```json
{
  "version": 1,
  "owner": "yxz",
  "updatedAt": "2026-11-10T01:58:00.000Z",
  "dirty": false,
  "parts": {
    "left_wrist": {
      "name": "左腕",
      "flags": ["需治疗"],
      "note": "打字时酸痛，久坐后加重",
      "since": "2026-11-08T10:00:00.000Z",
      "updatedAt": "2026-11-10T01:58:00.000Z",
      "history": [
        { "time": "2026-11-08T10:00:00.000Z", "flags": ["需治疗"], "note": "开始酸痛" }
      ]
    }
  },
  "snapshots": [
    { "time": "2026-11-10T01:58:00.000Z", "parts": { "left_wrist": { "flags": ["需治疗"], "note": "...", "since": "2026-11-08T10:00:00.000Z" } } }
  ]
}
```

- `since`：该部位**首次被标记异常**的时间，用于计算「异常 X 天」；恢复正常时置为 `null`。
- `dirty`：是否有改动尚未写成文件（页面内提示用，保存后为 `false`）。

- `parts`：每个部位一条记录，`history` 是该部位的历次自动保存快照（1 分钟内同状态合并）；
- `snapshots`：全身快照列表（自动保存时生成，10 分钟内合并；「全局存档」按钮强制生成独立存档）；
- `owner`：身份字段，用于导入校验。

## 七、如何维护部位清单（加部位 / 删部位 / 改部位）

打开 `文档\部位维护表.xlsx` 的「部位清单」工作表：

| 想做什么 | 怎么做 |
|---|---|
| **新增部位**（如喉咙、下颌） | 在表末尾浅蓝色空白行填写：部位ID（可留空由 AI 生成）、部位名称、所属视图（正面/背面/双面）、身体区域、对称性（左/右/中线），「状态」列选 **新增** |
| **删除部位** | 把该部位行的「状态」改为 **删除**（不用删行） |
| **修改部位** | 直接改「部位名称」，在「备注」写原因 |

改完后在 AI 对话中说一句「**部位表已更新**」，AI 会读取表格并把改动同步到网页（新增部位会画到人体图对应位置）。表内已有 50 个部位作为初始清单（v0.0.3 新增「生殖器」；v0.0.4 新增「肛门」；v0.0.7 新增「头发」，并把「左脚 / 右脚」拆成「脚背 / 脚底 / 脚趾」；v0.0.8 起脚部整体放大、改为三层结构，且**不分正反，正面背面都显示**）。

## 八、如何添加 / 修改需求（需求文档）

打开 `文档\需求文档.xlsx` 的「需求清单」工作表：

1. **新增需求**：在表末尾浅蓝色空白行填写——模块（整体/视觉/部位/交互/数据/历史/项目）、需求描述、来源填「用户」、状态选「新增」；
2. **回答待确认项**：如果某条需求状态是「待确认」，直接在「备注」列写答案并把状态改为「已确认」；
3. **改需求**：直接修改需求描述，或在备注中说明变化。

改完后在 AI 对话中说一句「**需求文档已更新**」，AI 会按表实施并把做完的需求状态改为「已完成」。

## 十、常见问题

**Q：数据会丢吗？**
页面内数据存 localStorage，一般不会丢；但清理浏览器缓存/Cookie 会清掉它。所以请定期点「保存到文件」把 JSON 存到 `数据备份\`，那才是真正的本地文件备份。

**Q：占多少空间？会不会越积越多？**
很小。单个部位完整记录约 0.3–0.5 KB，50 个部位全有记录约 18–28 KB，一条全身快照约 0.5–4 KB。快照已做裁剪（最近 300 条明细 + 周归档 + 月归档），长期稳定在 1 MB 量级，一个月大约只增长几百 KB 到 1 MB。

**Q：为什么打开页面不是自动读我上次保存的文件？**
浏览器安全策略禁止网页在你没有点击操作的情况下读写硬盘文件。页面会先显示上次的页面内数据；要读最新文件请点「高级设置 → 载入数据文件」，列表里会直接列出数据文件夹的 JSON。顶部若提示「● 未存盘」，说明有改动还没写成文件。

**Q：点「保存到文件」提示「请先在高级设置 → 保存路径中绑定数据文件夹」？**
v0.0.7 起保存路径统一在「高级设置 → 保存路径」里配置，保存时不再临时弹窗。进去点一次「选择 / 更换数据文件夹」，选到 `F:\AIproject\义体记录\数据备份` 即可，之后都是静默覆盖写同一个文件。

**Q：点「选择 / 更换数据文件夹」没反应 / 打不开选择框？**
v0.0.8 之前这个按钮的失败是被**静默吞掉**的（只有成功时才提示），所以看起来像「按键失效」。现在会明确告诉你属于哪一种：

| 现象 / 提示 | 原因 | 怎么处理 |
|---|---|---|
| 「已取消选择」 | 你在弹窗里点了取消 | 重新点一次即可 |
| 「选择窗口已打开，请先完成上一次选择」 | **连点两下**：上一次选择框还没关，浏览器拒绝再开一个 | 等上次的选择框关掉再点，别双击 |
| 「浏览器拦截了文件夹选择（SecurityError）」 | 页面没有真实的鼠标点击手势（比如页面还没激活、或在被嵌入的框架里打开） | 先用鼠标点一下页面空白处，再点按钮；用 Chrome / Edge 直接打开 `义体维护终端.html` |
| 「未获得读写授权」 | 弹窗里只给了「查看」权限，或点了拒绝 | 重新选择，弹窗底部选「允许 / 保存修改」 |
| 「系统层面操作失败（OperationError）」 | 目标目录在**网络盘 / 移动硬盘掉线 / 云端占位文件夹**上 | 换到本机磁盘目录（如 `数据备份\`） |
| 「该文件夹不可写入」 | 选到了系统保护目录（如 `C:\`、`Program Files`） | 换普通目录 |
| 「未配置（上次绑定 xxx，需重新授权）」 | 浏览器重启或清了站点数据，句柄还在但授权过期 | 点一次「选择 / 更换数据文件夹」重新授权 |
| 重开页面后绑定丢失 | 浏览器禁用了 IndexedDB（隐私模式 / 企业策略） | 每次打开页面重新选择一次目录 |

另外两种环境性原因：用 **Firefox / Safari** 打开时接口本身不存在（会提示「当前浏览器不支持」）；用**其他浏览器内核**或极旧版本 Chrome 也会失败。推荐 Chrome / Edge。

**Q：脚为什么是三块？哪块是脚背？**
v0.0.8 起脚部放大并拆成三层，三块在正面、背面**都会显示**（不分正反）：
- **脚背**：脚的上表面，从脚踝向前下方那一大块（原来的「脚掌」已改名为「脚背」）；
- **脚趾**：脚背的最前端，脚尖位置；
- **脚底**：紧贴脚背下方的一条，脚掌底面。

三块各自独立记录状态，脚趾发麻就点脚趾，足底筋膜炎就点脚底。

**Q：选文件夹时选错了地方？根目录那串路径是真的吗？**
再点一次「选择 / 更换数据文件夹」换目录即可。另外浏览器出于安全不会把真实绝对路径告诉网页，「保存路径」里显示的路径是按「项目根目录」拼出来的参考值，可直接在输入框改成你的实际路径。

**Q：人体图现在比以前亮很多，能调暗吗？／会不会卡？**
v0.0.9 的全息层是纯 SVG 滤镜 + CSS，没有任何图片或外部库，仍是单文件、`file://` 直接打开。如果觉得太亮，改这几个值即可（都在 `义体维护终端.html` 的 `<style>` 里）：
- `.hl-glow{opacity:.55}` ← 外发光强度，调小更暗
- `.hl-tex{opacity:.26}` ← 身上横向扫描纹理浓度
- `.hl-aber{opacity:.45}` ← 彩色错位强度，设 `0` 可关掉
- `.hud-br{stroke-opacity:.5}` ← 琥珀框线明暗
- `.part.breathe{animation:breatheK 2.4s ease-in-out infinite}` ← 呼吸光节奏，`2.4s` 改大更慢更平静
- `.part.scan-up .sf{stroke-width:2.3}` ← 光带扫过时的描边加粗程度

**Q：呼吸光看着晃眼／想要以前的「扫过才闪」？**
呼吸光是 v0.0.10 按需求把一次性闪烁改平滑后的方案。想调轻：把 `@keyframes breatheK` 里 `50%` 帧的两个 `drop-shadow` 数值调小（如 `5px→3px`、`20px→10px`）；想彻底关掉：把 `.part.breathe{...}` 整行删掉，只留扫描增强即可。
性能方面：滤镜只挂在**整层包裹组**上（全图共 2 个模糊滤镜），不是挂在 50 个部位上，所以不会因为部位多而掉帧；扫描每 40ms 只是取一次元素位置，和 v0.0.8 一样。

**Q：载入时提示「信息错误」？**
该 JSON 文件的身份不是 yxz（是别人的数据），系统拒绝载入以防数据混淆。确实需要时请联系 AI 修改网页中的身份常量。

**Q：点了历史快照的「恢复」但没变化？**
v0.0.3 起「恢复」会立即自动保存生效；如果没变化，检查是否处于快照回看模式（回看模式为只读，需先点「返回当前」）。

**Q：想加新部位（如喉咙）怎么办？**
见第七节——在《部位维护表.xlsx》里加一行并标记「新增」，然后告诉 AI。

**Q：换电脑怎么迁移数据？**
旧电脑「保存到文件」→ 把 JSON 拷到新电脑 → 打开网页「高级设置 → 载入数据文件」。新电脑进「保存路径」重新绑定数据文件夹即可。
